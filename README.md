# 📊 Bottleneck Dashboard | Power BI

An interactive **Bottleneck Dashboard** developed using **Microsoft Power BI** to analyze sales, orders, cancellations, returns, regional performance, and monthly sales trends.

## 🎯 Project Objective

The objective of this project is to transform raw business data into an interactive Power BI dashboard and identify important sales and order performance insights.

The dashboard helps analyze:

* Completed Sales
* Cancelled Orders
* Average Order Value
* Returned Products
* Regional Performance
* Category-wise Sales
* Order Status
* Monthly Sales Trends
* Sales Agent Performance

## 📌 Key Performance Indicators (KPIs)

### 💰 Total Completed Sales

Displays the total sales generated from completed orders.

### ❌ Total Cancellations

Shows the total number of cancelled orders.

### 🛒 Average Order Value

Calculates the average value of orders to understand the typical order size.

## 📊 Dashboard Visualizations

### 🔹 Most Returned Product

A bar chart that identifies products with the highest number of returned orders.

This helps in understanding which products may require further analysis regarding product quality or customer satisfaction.

### 🔹 Regional Sales by Category

A matrix visual that compares completed sales across different regions and categories.

This helps identify high-performing regions and categories.

### 🔹 Order Status by Region

A visual that compares different order statuses across regions, helping analyze completed and cancelled orders geographically.

### 🔹 Monthly Sales Trend

A line chart showing completed sales over time.

This helps identify monthly sales patterns, growth, fluctuations, and high-performing periods.

## 🎛️ Interactive Filters

The dashboard contains interactive slicers for:

* 🌍 Region
* 📦 Category
* 👤 Sales Agent

Users can select different values from the slicers to dynamically analyze the dashboard.

## 🧮 DAX & Calculations

DAX measures were used to calculate important business metrics such as:

* Total Completed Sales
* Total Cancellations
* Average Order Value
* Returned Orders

These calculations make the dashboard dynamic and responsive to user selections.

## 📈 Key Analysis

The dashboard can be used to answer important business questions:

* Which product has the highest number of returns?
* Which region generates the highest completed sales?
* Which category performs best in each region?
* Which region has more cancelled orders?
* How do sales change month by month?
* What is the average order value?
* How does sales performance change for different sales agents?
